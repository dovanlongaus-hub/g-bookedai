Booking Status Machine

Complete state transitions with triggers and actions

DRAFT → HOLD (10min) → PENDING_PAYMENT → CONFIRMED

From CONFIRMED:

CONFIRMED → RESCHEDULED
CONFIRMED → CANCELLED → REFUNDED
CONFIRMED → NO_SHOW

Triggers & Actions per Transition

TransitionTriggerActions
DRAFT → HOLDPOST /booking/holdReserve slot, start 10min timer (cron)
HOLD → expiredCron: /cron/expire-holdsRelease slot, delete hold
HOLD → PENDINGPayment initiatedStripe checkout or bank transfer started
PENDING → CONFIRMEDStripe webhook / Admin approveEmail, Calendar, Meet link, WhatsApp, audit log
CONFIRMED → RESCHEDULEDPOST /booking/rescheduleUpdate Calendar, notify, audit log
CONFIRMED → CANCELLEDPOST /booking/cancelRelease slot, refund check, email, audit log
CANCELLED → REFUNDEDStripe refund APICredit note, email, Xero sync
CONFIRMED → NO_SHOWT+15min auto-detectEmail, reschedule offer, admin alert
