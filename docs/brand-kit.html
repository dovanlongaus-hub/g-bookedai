Standards

Usage Guidelines

Rules for maintaining brand consistency across all touchpoints

✓ Do

  • Use the logo on dark backgrounds (#0a0a0f to #1e293b)
  • Maintain minimum clear space equal to the icon height around the logo
  • Use the indigo-to-cyan gradient for emphasis and CTAs
  • Apply glass-morphism with subtle borders (rgba white 8-12%)
  • Use Outfit font at weight 600-800 for headings
  • Maintain WCAG AA contrast ratios (4.5:1 minimum)
  • Use the icon-only variant at sizes below 32px
  • Apply negative letter-spacing (-0.5 to -2px) on headings
  • Use semantic colors consistently (green=success, red=error)
  • Prefer the cyan accent for interactive/AI-related elements

✗ Don't

  • Never stretch, skew, or rotate the logo
  • Never change the logo colors outside the approved palette
  • Never place the logo on busy or low-contrast backgrounds
  • Never use drop shadows on the logo
  • Never use the wordmark below 100px width
  • Never mix fonts — Outfit is the only typeface
  • Never use pure black (#000000) for backgrounds
  • Never apply glass effects without backdrop-filter support check
  • Never use more than 2 brand colors in a single component
  • Never use light theme colors on dark backgrounds or vice versa
