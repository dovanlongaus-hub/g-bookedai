🔐Dual Authentication System

Primary: Firebase Auth (Google Sign-In)

sequenceDiagram participant U as User participant F as Frontend participant FB as Firebase participant API as API Server participant DB as PostgreSQL U->>F: Click "Sign in with Google" F->>FB: signInWithPopup(GoogleAuthProvider) FB-->>F: ID Token F->>API: Bearer {idToken} API->>FB: verifyIdToken(token) FB-->>API: {uid, email, name} API->>DB: SELECT by google_sub alt New user API->>DB: INSERT user (role: customer) end API-->>F: Auth payload F->>F: Store token, redirect

Fallback: OpenAI OAuth (ChatGPT Sign-In)

sequenceDiagram participant U as User participant F as Frontend participant API as API Server participant OAI as OpenAI Auth participant DB as PostgreSQL U->>F: Click "Sign in with ChatGPT" F->>API: GET /auth/openai/login API->>OAI: Redirect (client_id, scope) OAI-->>U: OpenAI login page U->>OAI: Authenticate OAI->>API: Callback (code, state) API->>OAI: Exchange code → token OAI-->>API: access_token + user info API->>DB: Find/Create by openai_sub API->>API: Sign JWT (7 days) API->>F: Redirect with token F->>F: Store JWT, redirect
