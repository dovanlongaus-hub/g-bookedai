# bookedai.au + longcare.au — 2-Week Coding Start Package

**Positioning:** bookedai.au — AI Revenue Engine Platform  
**Slogan:** Turn customer intent into revenue — automatically

This package is designed to help developers start coding immediately while keeping the project aligned with Google Cloud, Gemini, Google Workspace, payment, learning, marketing, accounting, QA/UAT, and production operations.

## Folder structure

```txt
bookedai_longcare_2week_coding_start/
├── docs/      # PRD, architecture, daily tasks, Google AI setup guide
├── configs/   # agent configs, env example, API contracts
├── trackers/  # roadmap backlog, UAT, QA, A/B test CSVs
└── infra/     # Docker, Cloud Run, CI/CD guidance
```

## Start here

1. Read `docs/01_MASTER_IMPLEMENTATION_PLAN.md`
2. Execute `docs/02_DAILY_TASKS_14_DAYS.md`
3. Follow `docs/03_GOOGLE_AI_START_GUIDE.md`
4. Give developers `configs/07_API_CONTRACTS.yaml`, `configs/08_DATA_MODEL.sql`, and `configs/09_ENV_EXAMPLE.env`
5. Track work in `trackers/roadmap_backlog_14_days.csv`

## Build principle

```txt
Revenue first → Truth first → Google first → Container first → Web/PWA first
```

- g.bookedai.au AI search/chat entry
