# 12 — QA / UAT / Random Checks

## Functional test groups

1. Search → Service result
2. Booking hold
3. Payment by card
4. Bank transfer pending flow
5. Booking confirm
6. Calendar + Meet creation
7. Gmail confirmation
8. Dashboard display
9. Learning summary + Q&A

## UAT scenarios

- New user books a $29 trial.
- Returning user books a $99 session.
- User pays by bank transfer and admin confirms.
- User cancels more than 24h before session.
- User completes session and sees notes + next CTA.
- Admin views daily revenue and booking list.

## Random checks

- random booking audit
- random payment vs booking status audit
- random email template review

Weekly:
- random transcript quality review
- random CTA placement review
- random accounting reconciliation
